# 0.4.9：60 Hz 跟随鼠标箭头

右侧「手机跟随光标」开关现在显示白色填充、黑色描边的鼠标箭头。箭头尖端对应电脑鼠标点击位置。

目标采样刷新率提高到 60 Hz。采样和发送在同一计时回调中完成，并用带序号的累计确认替代逐条等待。
最多允许 3 条在途更新；手机只绘制最新收到的位置，网络卡顿时不会无限积压旧轨迹。
实际显示刷新率仍受手机屏幕、Wi-Fi 抖动、投屏和系统负载影响。

所有原有隐藏条件、断连清理和输入隔离保持生效。开关默认关闭。
请同时更新 QtScrcpy.exe 与 qtscrcpy-cursor.jar；协议版本升级为 2，旧组件会被识别并提示。

确认时间戳表示手机已提交显示层事务，不代表屏幕像素已经发光。精确的鼠标到屏幕物理延迟需要高速摄影或光电测量。
