# 鼠标按键映射 — 0.2.0-rc.2

本版继续沿用 8× 操作宏和 UHID 分支，新增绑定输入框的鼠标选择与侧键捕获，并修正鼠标映射的运行路径。音频模块和 sndcpy 未修改。

## 使用

1. 完整解压新的运行包，启动 QtScrcpy.exe，连接手机并打开投屏。
2. 从投屏工具栏播放圆圈进入 Action Macro，再打开“按键映射设置”。
3. 添加或选择点击、摇杆或滑动控件。
4. 在绑定框右侧的小箭头菜单中选择鼠标左键、右键、中键、侧键 X1（后退）或侧键 X2（前进）。也可以把鼠标停在绑定框上，直接按右键、中键或侧键绑定；键盘键仍可以直接绑定。
5. 普通左键点击绑定框只是选择输入框，不会覆盖当前绑定。需要绑定左键时，请明确从箭头菜单选择“鼠标左键”。中键是按下滚轮，不是滚轮上下滚动。
6. 拖动画面中的标记到目标位置，保存并应用。回到投屏后按映射切换键启用（默认反引号键，与 ~ 共用），再操作鼠标。

也可以为映射切换键选择鼠标按钮。此按钮必须与动作绑定不同。右键/中键用作切换键时优先切换映射，不再被普通模式的返回/主页快捷操作吞掉。

## 格式与兼容

| 按钮 | JSON 名称 | 兼容别名 |
|---|---|---|
| 左键 | LeftButton | — |
| 右键 | RightButton | — |
| 中键（按下滚轮） | MiddleButton | 旧 Qt 别名保持可读 |
| 侧键 X1（后退） | BackButton | XButton1、ExtraButton1 |
| 侧键 X2（前进） | ForwardButton | XButton2、ExtraButton2 |

同一按钮的别名按同一输入检查冲突。鼠标与键盘分别标识，避免某些额外鼠标键和键盘键的数字编号碰撞。操作宏仍记录映射后的手机动作，而不是依赖回放时的鼠标配置。

底层鼠标分发按实际映射类型处理：点击/按住、双触发、顺序点击、摇杆、滑动及 Android 按键；编辑器的可视化创建范围仍为点击、摇杆、滑动。切出映射会释放残留输入并取消尚未执行的映射定时动作。按住已映射的左键移动鼠标时，不额外生成跟随光标的普通触摸。

## 边界与验收

本版首先面向 Windows x64；构建和自动化测试不等于具体鼠标、驱动、手机及游戏验收。更多额外鼠标按钮仅在 Windows/Qt 实际收到独立按钮事件时才能直接捕获。DPI 键、板载宏键等可能不向系统上报鼠标按钮；若驱动把侧键改成键盘键，输入框收到的也会是那个键盘键。

本次不增加滚轮方向映射、鼠标按键组合、图像识别或仿真随机化。先在安全应用测试两个侧键的单次点击和按住，再测试滑动、录制回放以及暂停/停止。默认分支和 UHID 原分支不合并、不覆盖。
