# QtScrcpy + ScrcpyKeyMapper 0.3.0-rc.1

本版将 w4po/ScrcpyKeyMapper 的真实网页编辑器嵌入 QtScrcpy，固定到提交 022870e2caf905046c8e7502d4053bb5f171c1e4，保留 MIT 版权声明。不是重新画一套类似外观。点击、四向摇杆、滑动、多次点击和视角等节点由上游 JavaScript/Konva 绘制与编辑；QtScrcpy 原生映射器负责执行。

## 入口与保存
完整解压运行包（不要只复制 exe）。连接手机并打开投屏，停止宏后，从投屏工具栏播放圆圈打开 Action Macro，再点“按键映射设置”。打开的是内置 ScrcpyKeyMapper 窗口，不需要启动浏览器或访问网页。

编辑时自动载入当前画面快照与配置，可同时查看整套键位。双击右侧类型或拖到画布添加节点；选择节点后编辑参数。左下/右侧布局以实际编辑器为准，显示可随窗口缩放。

点击按键框后可以按键盘键，或在框内按右键、中键、X1、X2。左键仅选中输入框，需要绑定左键时使用编辑器顶部的“左键”按钮；顶部也可直接选两个侧键。中键指按下滚轮，不是滚动方向。

底部“导入 JSON”“保存”“保存并应用”使用原生文件对话框。“保存并应用”后回到投屏按映射开关键启用（默认反引号，与 ~ 共用）。未保存修改关闭前确认；连接中断会关闭编辑器并禁止应用到新的设备会话。

## 原有补丁已合并
- 普通映射保留可见鼠标，不将移动自动转换成手机滑动。鼠标视角为独立开关，新方案与缺少明确开关的旧方案默认关闭；旧视角参数不被删除，需要 FPS 视角时明确启用。
- 未绑定的侧键不再回退为光标位置的普通触摸。已经绑定的按钮即使临时释放视角鼠标也执行原映射。
- 已映射键交给原生触摸映射；其余键在启用 UHID 时继续作为实体键盘输入。按下/松开保持同一输入通道，映射占用的修饰键不混入其他 HID 按键。
- 光标隐藏与恢复限定到当前投屏控件，退出/替换/失去焦点时清理捕获，避免隐藏残留。
- 8×、宏暂停/继续、时长停止、老 v1/v2 录制保留。音频与 sndcpy 未修改，未应用音频补丁。

## 数据与网络
编辑器在独立的内存 WebEngine profile 中运行；JS/CSS 依赖固定版本并编入程序资源。运行时不依赖 CDN，没有向网站发送截图、配置或设备信息。页面只能获得当前快照与配置并通知就绪/修改；不能执行任意命令、读写任意文件或直接控制手机。保存仍经 C++ 校验与原生对话框。

## 限制
- 这是快照编辑，不是实时游戏上的常驻键位浮层。操作宏与按键映射是独立功能。
- KMT_ANDROID_KEY 等上游未提供可视化控件的扩展配置会提示并原样保留，不假称可编辑全部类型。
- 保存拒绝冲突键位、不合法坐标、异常数字、过大/过深 JSON；不要导入来源不明的配置。鼠标侧键是否报告为独立按钮取决于驱动。
- 旧 FPS 配置需要重新明确开启鼠标视角；不会默认隐藏鼠标。没有新增随机化仿真、滚轮方向绑定或 MuMu 私有脚本导入。
- 自动构建、单元和模拟输入测试不等于实体手机/鼠标/游戏验收。先用安全页面测试未绑定字母、侧键目标位置、空移动不滑动，再测试录制和回放。
- 引入 Qt WebEngine 后运行包显著增大。不要删除 QtWebEngineProcess、resources 或 qtwebengine_locales 等依赖。
