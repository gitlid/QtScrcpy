# QtScrcpy + ScrcpyKeyMapper 0.3.0-rc.1

本版真正嵌入 w4po/ScrcpyKeyMapper 网页编辑器，固定上游提交 022870e2caf905046c8e7502d4053bb5f171c1e4，保留 MIT 版权声明。点击、四向摇杆、拖动、多次点击和视角等节点由上游 JavaScript/Konva 绘制与编辑；QtScrcpy 原生映射器负责执行，不是第二套映射引擎。

## 使用
完整解压运行包，不要只替换 exe。连接手机并打开投屏，停止宏，从工具栏播放圆圈进入 Action Macro，再点击“按键映射设置”。打开的是内嵌 ScrcpyKeyMapper 窗口，不必启动浏览器或访问在线网站。

自动载入当前画面快照和配置，整套键位同时显示。双击右侧类型或拖到画布添加节点；选择节点编辑参数。点击按键框后可按键盘键，或在框内按右键、中键、X1、X2。左键点击输入框仅选择；需要绑定左键时使用上方“左键”按钮。其他鼠标按钮也可从上方选择。中键指按下滚轮，不是滚动方向。

底部“导入 JSON”“保存”“保存并应用”采用原生文件对话框。保存并应用后，回到投屏按映射开关键启用，默认反引号（与 ~ 共用）。关闭时会询问未保存修改，断连会关闭编辑器，禁止把旧会话编辑应用到新设备。

## 鼠标视角与 UHID
新建普通方案默认关闭鼠标视角，移动鼠标不会自动滑动手机。

旧 FPS 方案如果原本有 mouseMoveMap 而没有显式开关，保留其原有视角行为，并在编辑器顶部明确勾选显示。只需要侧键映射时，请取消“鼠标视角：隐藏鼠标并将移动转换为拖动”，保存并应用。取消不会删除原视角参数；需要时可重新启用。不会为了默认值改变所有历史游戏方案。

未绑定侧键不再变成光标处的触摸；绑定的按钮执行对应动作，在临时释放视角鼠标后仍有效。光标状态限定到当前投屏控件，退出/编辑/替换时释放。

已绑定键由原生映射处理，未绑定键在 UHID 开启时继续作为实体键盘输入；按下和松开保持同一通道。映射占用的修饰键不混入其他 HID 按键。只绑定 X1/X2 时，字母和 WASD 可以继续走原生 UHID；W 已绑定摇杆时不会同时输入字母 W。

已有 8×、录制和回放的暂停/继续、时长停止、v1/v2 宏兼容保留。音频和 sndcpy 不修改，未加入音频补丁。

## 离线资源与限制
JavaScript/CSS 依赖固定版本，并编入程序资源。运行时不访问 CDN，不向网站上传截图、配置或设备信息。页面只接收快照/配置并通知就绪/修改；不能直接运行命令、任意读写文件或控制手机。保存经原生对话框和 C++ 校验。

这是快照编辑，不是游戏实时画面中的常驻键位提示层。上游不提供可视化节点的 KMT_ANDROID_KEY 等扩展配置会提示并原样保留。来源不明的配置不要导入；非法或冲突绑定、越界坐标、异常数字、过大/过深 JSON 会拒绝保存。

没有新增仿真随机化、滚轮上下绑定、MuMu 私有宏格式导入或自动开机/重连执行。侧键识别仍取决于驱动是否上报独立鼠标事件。

引入 Qt WebEngine 后运行包显著增大，不要删除 QtWebEngineProcess.exe、resources 或 qtwebengine_locales。构建和模拟输入测试不等于实体手机/鼠标/游戏验收。先在安全页面验证未绑定字母、侧键位置、关闭视角后空移动无触摸，再测试操作宏。
