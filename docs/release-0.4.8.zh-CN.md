# 0.4.8：手机跟随光标

连接手机后，点击投屏右侧工具栏的鼠标箭头按钮「手机跟随光标」。按钮亮青色表示开启。
鼠标移到投屏画面中时，手机相同位置会显示青色圆环，圆环中心对应电脑鼠标的点击位置。
再次点击按钮关闭。每次新建投屏会话默认关闭。

- 不需要点击或按住鼠标；圆环本身不发送输入、不拦截手机触摸，不修改现有映射、UHID 和操作宏。
- 鼠标离开画面、进入侧栏、窗口失去焦点、最小化、弹出对话框、播放操作宏或启用游戏鼠标视角时隐藏。
- 支持缩放、窗口大小调整、手机横竖屏切换及「仅旋转投屏画面」的坐标转换。
- 适用于 Android 10 及以上的主屏幕完整投屏。裁剪、虚拟/副屏、相机和锁定采集方向时按钮不可用。
- 已在 V1824A / Android 11 / Wi-Fi 上验证手机端显示层。其他系统如果不允许创建显示层，会提示并自动关闭此开关。
- 位置通过当前 ADB 连接实时传输，刷新上限约 30 次/秒，实际延迟受 Wi-Fi 和投屏延迟影响。
- 圆环属于手机屏幕内容，也会出现在投屏、截图和录屏中。断连时约 1.2 秒隐藏，约 5 秒后辅助进程退出。

构建时需要 Python 3.10+ 和 Java 17+，CMake 使用 SHA-256 固定版本的 ECJ 和 D8 编译辅助 JAR。
构建工具只缓存在构建目录，运行包只包含自有辅助程序 `qtscrcpy-cursor.jar`，使用者无需安装 Java 或 APK。
