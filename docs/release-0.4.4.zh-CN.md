# QtScrcpy 0.4.4-rc.1：最近任务兼容与应用菜单修复

在0.4.3及保留脚本覆盖更新器基础上继续，不改变宏格式、键位格式、音频、UHID和仅旋转电脑画面功能。

## 界面

取消标签栏原生左右滚动按钮，滚轮不再切换标签；放不下的应用通过 > 访问。
> 每项为“图标/名称 + 右侧 ×”：点名称切换，点 × 请求关闭，不再设置单独的关闭子菜单。
× 保持可见，悬停时强调，便于发现；同步失效、应用退出或正在关闭时置灰。前台应用在列表高亮。
标签本身使用清晰的 ×；桌面没有关闭按钮。确认默认取消；关闭前会停止宏、录制和自动返回。
关闭仍为强制停止，不卸载、不清除已保存数据，但未保存操作、通知及后台任务可能受到影响。
菜单打开期间也跟随下一次成功任务读取刷新；弹确认框期间切换 Android 用户时，旧确认不再对新用户有效。
若手机仍保留最近任务卡片，会如实保留并提示，不能为了“立即消失”伪造同步成功。

## 最近任务与名称

补充 mUserId、带空格字段、ComponentInfo{包名/组件} 和 {包名/组件} 格式；可从任务自身 Intent 读取缺省组件。
在主任务段格式不可识别时，尝试同一次读取的 Visible RecentTaskInfo 段，不把普通后台进程或嵌套子 Activity 当最近任务。
应用名称或包名含 Exception 不再被误判为 ADB 异常；只有明确的错误行会触发失败。
保留首尾用户校验、失败保留最后列表、禁止未知用户关闭等保护；空任务响应不等于查询失败。
修复名称异步读取成功后，状态栏仍停留在旧名称/“名称未读取”的问题。名称缓存和脚本不重置。
查询仍每秒尝试、无重叠，单次超时6秒；实际延迟依赖手机和ADB，不是瞬时通知。

## 诊断

截图本身不能确定该手机的完整 dumpsys 输出，所以本版不宣称已完成该机型验收。
如果仍失败，悬停状态栏可看具体原因；右键状态栏可“立即重试最近任务同步”或“复制同步诊断”。
诊断仅包含结果码、输出长度与字段计数，不复制任务正文、Intent 参数、应用包名清单或用户脚本；不会自动上传。
需要继续定位时把这段诊断提供出来即可，不必先上传宏或全部配置。

## 更新

使用配套0.4.4保留脚本覆盖更新器，保存录制并退出旧程序；更新器解压到旧目录外，选旧 QtScrcpy.exe 后备份并覆盖。
不将新包 config/keymap 示例覆盖旧文件；AppData及外部脚本位置不修改。旧目录完整备份，程序恢复不回退新写的脚本。
也提供完整程序 ZIP，供新目录安装或开发检查；已有数据用户优先使用配套更新器，不直接解压覆盖。

自动化测试使用构造的ROM输出和Qt事件；不能替代你的真实手机输出、USB/Wi-Fi延迟或游戏触控验收。
