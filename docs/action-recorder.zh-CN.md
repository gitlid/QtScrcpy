# 操作宏（录制与回放）

此分支为每个已连接的显示设备提供独立的操作宏。它记录 QtScrcpy 已经转换好的 Android 控制消息，因此普通鼠标操作和游戏键位映射生成的触摸动作都能按录制时的含义回放，不依赖回放时的键位配置。

## 使用方法

1. 连接手机并打开投屏窗口。
2. 点击右侧工具栏中的播放圆圈图标，打开“Action Macro”窗口。
3. 点击“Start recording”，在投屏窗口中完成点击、长按、滑动、滚轮或键盘操作。
4. 点击“Stop recording”，然后点击“Save...”保存为 `*.qsmacro.json`。
5. 可设置重复次数和每轮间隔；重复次数设为 0 表示持续循环，直至手动停止。
6. 点击“Play”开始回放。点击“Emergency stop”或在投屏窗口按 `Ctrl+Shift+X` 可立即中止。

紧急停止、设备断连以及每轮循环结束时，程序都会为仍处于按下状态的按键和触点补发释放消息，避免手机端出现“按键卡住”或“触点未抬起”。

## 文件格式与校验

脚本使用带格式标识和版本号的 JSON，事件保存相对时间以及按键、触摸、滚动等语义字段，不保存 scrcpy 的私有原始通信字节。触摸事件还包含录制时的画面尺寸与方向元数据。

加载时会校验格式版本、事件数量、时间顺序、最长时长、字段类型、坐标和画面尺寸。单个脚本最多 100,000 个事件、最长 24 小时、文件最大 64 MiB。包含文字或剪贴板输入的宏会在 JSON 中保存对应文本，请不要把含敏感内容的脚本分享给他人。

## 当前范围

- 支持单设备录制、保存、加载、单次/多次/持续循环回放及紧急停止。
- 支持转换后的点击、长按、滑动、滚轮、键盘和游戏映射动作。
- 回放使用录制时的绝对设备坐标；在不同分辨率、裁剪区域或方向下使用前应重新录制。
- 本功能不包含图像识别、条件等待、步骤编辑和多设备同步调度。
