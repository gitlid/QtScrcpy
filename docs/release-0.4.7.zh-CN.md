# 0.4.7-rc.1：侧边栏滚轮修复

修复鼠标停在侧边栏按钮或按钮间空白处时，滚轮不能上下滑动的问题。原先只有滚动视口直接收到滚轮事件时才会滚动，按钮所在控件会拦住事件。

现在按钮、禁用按钮、空白区域和滚动视口都由侧边栏统一处理滚轮。支持上下滚动及触控板像素滚动；到达顶部、底部或不需要滚动时，事件仍不会传给手机，也不会触发按钮、改变音量或抢走键盘焦点。独立弹出的菜单保留自身的滚轮行为。

新增回归向实际按钮和嵌套子控件发送事件，并核验滚动条位置变化、滚动边界、焦点和手机事件隔离。已有工具栏一体化、左右系统面板、宏、UHID、键位和旋转功能保留。

更新前保存录制并从系统托盘退出程序。覆盖程序时保留 config、keymap、脚本和 AppData 中的应用配置及方向备份。
