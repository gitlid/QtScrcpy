# 应用标签与预制操作（0.4.1-rc.1）

连接手机投屏后，画面上方显示应用标签、`>`、`+`、键位、操作。此版本沿用 0.4.0 的配置目录、键位 JSON 和宏格式，不会自动覆盖已有用户文件。

## 名称与应用标签

- 标签显示手机系统返回的本地化应用名称，而不是包名。包名保留在悬停提示和添加应用窗口的第二行，仍可按包名搜索。
- 点击 `+`，按应用名称或包名搜索，然后打开应用。点击已有标签切换到相应应用；手机上手动切换时，标签跟随前台更新。
- 投屏服务可能已清理手机上的服务 JAR。名称查询失败时，程序会从本运行包的 scrcpy-server（或原 QTSCRCPY_SERVER_PATH）上传一个独立、随机命名的查询副本，执行只读的应用列表查询；不覆盖、不终止现有投屏服务。查询副本由 scrcpy 自清理。
- 中文、emoji 和换行以原始 UTF-8 字节完整收集后解析，兼容长名称导致包名换行的输出。
- 名称缓存按手机身份保存；同一手机换 USB/Wi-Fi 地址仍可复用。刷新失败保留已确认名称，不把包名误存为友好名称。首次未能读取时显示“名称未读取”，可在 `+` 中点击“刷新名称”；没有猜测或硬编码应用名称。
- 名称来自 Android 应用标签，不保证跟随第三方桌面为快捷方式手工设置的别名。
- “手机桌面”打开桌面；标签的 × 移除标签，不卸载应用。目前每台手机最多保存 32 个应用标签。

## 标签超出宽度

超出可用宽度时，标签栏右侧显示明确的 `>` 按钮。点击展开未完整显示的应用（包括被边缘裁切或名称省略的标签），按名称选择即可切换。不需要逐次点滚动箭头寻找应用。调整窗口宽度、切换前台、添加/关闭标签或刷新名称后，菜单会更新；所有标签都能展示时按钮隐藏。原生滚动按钮仍可使用。

## 按键方案绑定应用

切换到目标应用，点击“键位”，调整后“保存并应用”。方案绑定到截图所属的应用，不会因为编辑期间其他应用进入前台而绑定错应用。未设置应用方案的程序使用普通输入；已有全局方案仍保持兼容。宏执行期间不允许替换正在使用的映射器。

## 预制操作：允许切换，但自动返回绑定应用

1. 点击“操作”，选择绑定应用，录制或载入宏并保存。
2. 启动时先打开绑定应用，确认前台与画面尺寸后执行。
3. **运行中仍可点击顶部标签、`>` 菜单或 `+` 切换应用，也可进入手机桌面。** 不再拒绝标签操作。
4. 在发出标签切换命令之前先暂停脚本并释放输入，保留原绑定应用与执行进度。切换完成后，前台检测会把手机切回绑定应用，再继续剩余操作。再次切走仍会再次返回。
5. 快速连续点击多个标签时串行处理启动请求，后续以最后一次选择为准；切换进行中不会凭旧的前台结果恢复脚本。
6. **手动暂停**暂时关闭自动切回；点击继续时重新回到绑定应用。**停止 / Ctrl+Shift+X**结束宏并取消等待启动、待处理标签切换和自动切回。关闭投屏或断开设备同样停止。

“不锁定”指允许应用导航，不代表在其他应用里继续发送宏点击，也不允许录制过程中更换目标。`locked()` 是旧内部接口名，仍表示宏有绑定目标，不再表示禁止标签导航。界面编辑限制用于防止替换宏正在使用的输入配置。

## 边界

前台通常约每 250 ms 检查一次，切回后至少稳定 500 ms 并确认画面尺寸才继续；不是瞬时切换。失去前台检测、锁屏或尺寸不符会暂停。每次恢复最多自动尝试启动三次，15 秒内无法恢复则停止并报告。手动点击标签本身不计入自动恢复次数。

自动返回只恢复目标应用，不恢复游戏内部页面、人物位置或弹窗。中断的长按/拖拽会释放并按原暂停规则跳过动作组，不重新制造点击。

仍保留 8×、循环、有效时间和 v1/v2 宏兼容；音频、系统显示点按、底层键鼠映射和编辑器资源未修改。此版本为候选版；CI 使用虚拟命令响应和 Qt 事件，实体手机、应用名称查询和真实应用切换仍需用户验收。
