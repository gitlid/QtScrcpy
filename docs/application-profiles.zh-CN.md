# 应用标签与预制操作（0.4.0-rc.1）

连接手机投屏后，画面上方会显示应用标签。点击标签可切换到手机上的对应应用；手机上手动切换应用时，标签也会跟随前台应用更新。

## 添加与切换应用

- 点击标签栏的 **+**，按应用名称或包名搜索，选择后点击“打开应用”。
- “手机桌面”打开手机的桌面；标签上的 **×** 移除该标签，应用仍保留在手机后台。
- 标签使用名称首字徽标。名称通过当前 scrcpy 服务读取；读取失败时显示包名。
- 标签、按键方案和预制操作列表按手机身份保存。同一台手机的 USB 和 Wi-Fi 连接可复用配置；无法读取设备序列号时退回当前连接地址。

## 按键方案绑定应用

1. 切换到要配置的应用，点击上方“键位”。
2. 在编辑器中调整键位，点击“保存并应用”并保存 JSON。
3. 方案会绑定到截图所属的应用，并在该应用处于前台时启用。切换到其他应用会使用那个应用自己的方案；未配置的应用使用普通输入。

键位 JSON 仍可导入、导出，并携带 `applicationBinding` 元数据。应用配置保存到当前 Windows 用户的 QtScrcpy 配置目录 `app-profiles` 下；配置损坏时会保留原文件并报告错误，不会覆盖它。

尚未使用应用绑定的既有全局键位方案保持原有使用方式。录制或回放正在占用输入时，不会在中途替换映射器。

## 预制操作绑定应用

1. 点击上方“操作”，在“绑定应用”中选择目标。
2. 录制并保存，或载入已有的宏文件后选择应用，再保存。
3. 后续可在“已保存的预制操作”中载入该应用对应的文件。
4. 点击启动。程序先打开目标应用，确认它在前台且画面尺寸与录制一致后，开始执行。

运行时切换到别的应用，会暂停输入、释放按键与触点，切回目标应用后继续。横竖屏切换会等待录制时的画面尺寸恢复。已经中断的长按或拖动按现有暂停规则跳过该动作组，避免重复产生点击。

**暂停**允许暂时切换应用；点击继续时会先切回目标应用。**紧急停止 / Ctrl+Shift+X**同时取消等待启动、自动切回和回放。关闭投屏或断开手机也会停止，并关闭该会话自己的 ADB 请求进程。

“不绑定应用”用于已有的通用宏，保留原来的直接播放方式。宏文件中的事件格式、8× 倍率、暂停和循环设置保持兼容。

## 行为边界

应用切换检测存在短暂延迟。程序约每 250 毫秒检查一次前台窗口；查询停滞、锁屏、通知栏或无法确认目标时会暂停输入。目标应用最多尝试启动三次，15 秒内无法恢复则停止并显示原因。

自动切回负责打开应用，并不会替你恢复游戏内部的具体页面、人物位置或弹窗状态。启动前仍需确认录制起始页面。首次启动、加载界面和权限对话框也需要按实际应用处理。

此版本针对手机主显示屏投屏；摄像头预览和独立虚拟显示屏不显示应用标签。`0.4.0-rc.1` 是候选版本，具体手机与游戏的行为以实际验收为准。

## 验证

自动化测试覆盖应用列表与窗口解析、包名验证、配置持久化、宏绑定往返、启动前确认、切走与切回、手动暂停、紧急停止、断线、启动失败、前台检测停滞、重试上限及横竖屏恢复。核心回归另外验证应用映射切换释放输入，以及原有非绑定宏的画面保护。
