# 0.4.6-rc.1：一体式工具栏与系统面板

累计保留 0.4.3—0.4.5 的画面旋转、稳定展示方向、最近任务标签、应用名称与脚本保留更新工具，源码已统一到默认分支。

## 一体式工具栏

右侧按钮已嵌入投屏窗口，随窗口移动、最小化、最大化和全屏，不再生成独立悬浮工具窗口。工具栏占用独立区域，不遮挡手机画面；窗口较矮时可滚动访问其余按钮。工具栏滚轮不会传到手机。

原“显示工具栏”连接选项仍有效。旋转、宏设置、应用标签、截图、音量和其他入口保留；全屏也可以通过工具栏退出。

## 通知与设置面板

- 展开通知栏（Ctrl+N）：从手机原始画面左侧四分之一处的顶部下滑。
- 展开设置面板（Ctrl+Alt+N）：从右侧四分之三处的顶部下滑。

触摸通过 scrcpy 控制连接发送，不随电脑端“仅旋转画面”改变左右，也不受游戏按键映射影响。已展开的 NotificationShade 通知栏和 vivo 快捷中心先经前台窗口确认后收起，再执行下滑；只对已识别的系统面板发送返回键，不在普通应用中盲目返回。读取失败或面板没有收起时显示原因。

宏运行、暂停或自动返回任务占用输入时，不抢占输入。手动输入、停止、断线、原始画面尺寸变化及新面板请求会取消未完成手势并释放触点。普通录制可保留手势用于回放。

## 更新

本版保持 RC 候选标识。更新前保存录制并退出旧程序，保留已有 config、keymap、脚本及 AppData 中的应用配置和旋转恢复备份。不要把默认配置覆盖到自己的配置上。旧的 0.4.5 更新器内置 0.4.5 程序包，不是本版的更新器。

其他 ROM 的手势可能不同，需以对应手机表现为准。

本轮已通过 V1824A（Android 11）Wi-Fi 连接的核心控制接口实测：左侧通知中心、右侧快捷中心，以及从已展开通知中心到快捷中心的切换。其余设备需要实际确认。
