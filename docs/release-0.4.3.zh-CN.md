# QtScrcpy 0.4.3-rc.1

基于 dev 的 fc52b346（0.4.2-rc.1）继续修改。保留设备旋转、方向备份与恢复、应用名称、按应用键位、宏自动返回、8×、UHID、双击修复和离线键位编辑器。此版是候选版，不代表已经通过实体手机验收。

## 仅旋转电脑投屏画面

投屏右侧圆形箭头 → **仅旋转投屏画面（不改变手机）**：顺时针 90°、逆时针 90°、180°、恢复画面方向。

不要求手机或应用支持横屏，不执行 wm/settings，不修改手机方向、分辨率或 DPI，也不重启投屏服务。只是让电脑上的原始画面旋转，不会把竖屏应用重新排版成真正的横屏界面。手机旋转失败后可手动改选这个选项，不会未经确认替你改变另一种设置。

画面宽高比和普通鼠标点击、双击、拖拽、滚轮坐标一起转换；相对鼠标视角的边缘回定位也携带实际桌面坐标转换。解码帧、手机截图和已保存宏仍采用原手机坐标。改变显示角度前会询问是否停止运行/暂停中的宏及录制，取消不改变画面；停止录制不等于保存。

该选项用于普通显示的 OpenGL 渲染路径（包括本 Windows 64 位程序），不提供给 Metal 或动态虚拟显示。仅本次投屏会话保留显示角度，重新连接默认不旋转。原来的四项手机方向控制及方向备份仍在。

## 标签关联手机最近任务

连接后每秒发起一次有超时、无重叠的最近任务读取。仅显示当前 Android 用户、有启动入口的应用，按最近任务顺序去重；应用在手机中被移出最近任务后，对应标签随下一次成功读取更新。实际延迟取决于 ADB 和手机响应，不是零延迟通知。

关联的是 Android **最近任务列表**，不是所有后台进程/服务，也不保证每家 ROM 的桌面历史卡片过滤规则完全相同。桌面、SystemUI 等系统任务不提供关闭操作。原应用键位和宏配置保留，任务退出不会删除这些配置。

首次尚未同步时明确标记“暂显示历史标签”；解析失败、权限拒绝、查询超时或 Android 用户切换途中不会把失败当作空列表。保留最后列表并显示失去同步，关闭功能停用；重新读取成功后恢复。查询首尾核对 Android 用户，避免混用不同用户的结果。

## 在 > 菜单中关闭应用

`>` 原有应用条目仍直接切换应用；底部新增 **关闭后台应用（强制停止）** 子菜单，可选择相同隐藏应用关闭。标签的 × 也改为关闭应用并请求确认，不再仅隐藏标签。

关闭前弹出确认框，默认取消。确认后停止当前宏、录制、自动返回及排队导航，再对已确认的当前用户应用执行 `am force-stop --user <id> <package>`；在手机端写入前再次核对用户。它相当于强制停止，不是卸载，也不会清除已保存的应用数据，但未保存的操作可能丢失，通知/后台任务可能暂停至重新打开应用。

关闭结果会重新读取核对；失败不会假装移除了标签。如果 ROM 仍保留最近任务卡片，会明确提示并继续按手机列表显示，而不是制造一个假同步状态。关闭进行中禁止新的应用切换。断开设备时取消本会话尚未完成的 ADB 客户端请求；已到达手机的关闭命令无法撤销。

## 更新方式

关闭旧 QtScrcpy，将新版完整 ZIP 解压到新目录，运行该目录的 `QtScrcpy.exe`。不要只复制 EXE：需同时使用随包 Qt、核心库、ADB 和编辑器资源。保留旧目录以便回退；不要删除 QtScrcpy 配置目录、rotation-backups、应用配置和已有宏。自定义放在旧程序目录下的 config/keymap 文件请先备份，再按需迁移，不用新包默认文件覆盖自己的方案。

自动化回归覆盖任务解析、用户隔离、失败与旧响应、关闭确认/取消、宏停止、四方向坐标变换和实际 OpenGL 纹理旋转。真实手机（包括 V1824A Android 11）的 ROM 输出、任务关闭行为、实际触摸和游戏视角仍需验收。音频未改动。
