# QtScrcpy 操作宏与按键编辑 0.2.0-rc.1

此版本基于 UHID 分支继续开发，不替换默认分支。音频模块及 sndcpy 启动补丁均未改动；不做仿真/随机化操作。

## 操作宏执行设置

投屏工具栏的播放圆圈图标打开 Action Macro。停止条件支持按次数（1–9999）、按有效运行时间（1–86400 秒）、无限循环至手动停止。循环间隔为 0–600 秒，支持三位小数。

倍率：0.25×、0.5×、1×、1.5×、2×、3×、4×、6×、8×。上限在界面和核心执行器两处校验，NaN/无穷值和大于 8× 都会拒绝。倍率缩放录制内的事件时间和末尾等待；单独设置的循环间隔不缩放。手机应用、网络加载和动画不会加速，高倍率可能让长按失效或使按钮尚未出现就被点击。

有效执行时长包括轮间等待，不包括手动暂停。按时长停止时在下一次调度检查中停止并释放输入，不需要等当前轮结束。系统调度、网络和手机处理有延迟，不是硬实时保证。

保存宏时附加可选的 `executionSettings` 元数据，再次加载会恢复设置。既有 v1/v2 事件格式不变，旧录制无需转换；不支持的执行设置退回单次 1×，不会自动执行。修改执行设置后请再次保存。

## 暂停与继续

- “暂停”可在回放、轮间等待和录制过程中使用。暂停后投屏、声音和手机本身继续运行。
- Ctrl+Shift+P 暂停本进程已登记宏窗口的设备，不是继续快捷键。Windows 尝试全局注册，失败时界面明确显示应用内回退。Ctrl+Shift+X 仍为紧急停止。
- 点击“继续”恢复剩余等待和当前轮次，暂停期间的时间不会被当成迟到，不会集中补发动作。
- 如果暂停打断了长按、摇杆、拖拽或 UHID 组合键，会先释放输入。该连续动作无法无损恢复；继续前弹窗确认跳过当前动作组，直到下一个所有按键/触点都已释放的边界。不会重新点击，也不会自动恢复按住状态。
- 录制暂停时追加释放事件；暂停中的操作和停顿不录入。继续录制前清理手动输入。
- 暂停不等于结束。停止、断线、关闭和检测到显示尺寸变化会结束执行，不会因重连自行恢复。

客户端不能撤回已发送的输入，也不能保证断线后的释放指令到达手机。释放触点也可能被目标应用解释为点击完成。先在安全页面实测。

## 可视化按键设置（Windows）

入口：**投屏工具栏的播放圆圈 → Action Macro → 按键映射设置**。不是原来的应用脚本按钮。先停止操作宏，再进入编辑器。

编辑器使用当前手机视频画面的快照，不向手机发送编辑点击。可添加点击/按住、WASD 摇杆和滑动控件。选择列表中的控件，点击按键框后直接按键绑定；拖动圆点调整相对位置，滑动有起点/终点，摇杆可以调整相对范围。窗口显示和缩放时画面自动适应可用区域。

“保存并应用”写入 JSON 并应用到当前会话。返回投屏后按映射开关键启用（默认 Key_QuoteLeft，即反引号键）；再次按下切回普通/UHID 输入。默认保存到程序目录 `keymap`。下次连接前在主窗口刷新映射列表并选择保存的配置。

支持导入通过校验的已有配置，保留不直接编辑的扩展字段。现阶段可视化创建重点是点击、摇杆、滑动；复杂视角、多击等仍可沿用原有 JSON，不等于所有控件都有完整可视化编辑。绑定冲突、无效坐标、超出画面的摇杆、损坏/过大 JSON 会拒绝保存或导入。失败导入不覆盖当前编辑内容。绑定框主要录入单键；不提供任意组合键的映射编辑。

映射使用相对坐标，但不会识别应用布局；操作宏仍为记录时的设备坐标。手机旋转或布局改变需重新检查。编辑期间断开会取消应用到设备；已保存的文件保留。画面采集入口使用 Windows/OpenGL 投屏控件，本轮未提供 macOS Metal 编辑器适配。

## 本阶段不包含

不包含自动开机/重连执行、独立宏库管理器、图像识别、条件等待、按住连点/开关联点的新调度器、一键绑定宏、仿真随机化或 MuMu 私有脚本格式导入。先验收基础编辑器与 8×/暂停执行器，再扩展这些功能。

## 验收建议

先单次 1× 验证点击、长按、拖拽与 UHID；再测试 2×/4×/8×、三次循环、按时长停止；分别在等待、轮间等待、长按中暂停和继续，并测试紧急停止。按键编辑器先做一个点击映射，再测试摇杆和滑动。全局快捷键、实际安卓游戏语义和机型兼容性需要实体手机验证。
