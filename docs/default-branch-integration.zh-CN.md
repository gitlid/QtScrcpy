# 默认分支整合

完整增强功能统一进入主项目 `dev` 和核心库 `main`。包括操作宏、最高 8× 回放、暂停/继续、UHID 实体键盘、键鼠映射兼容修复，以及内嵌的离线 ScrcpyKeyMapper 编辑器。

主项目的 `QtScrcpyCore` 子模块固定到核心库中已经测试的具体提交。核心合并使用 merge commit 保留原有提交，因此不需要仅为追随分支末端而移动子模块引用。编辑器仍固定到 `022870e2caf905046c8e7502d4053bb5f171c1e4`。

## 默认分支检查

- 主项目 `keymapper-integration.yml` 在面向 `dev` 的 PR、`dev` 和完整功能分支提交、`keymapper-v*` 标签及手动运行时执行。覆盖 Windows x64 完整编译、原生回归、内嵌编辑器以及独立便携包启动检查。
- 核心库 `macro-v2.yml` 在面向 `main` 的 PR、`main` 和完整功能分支提交、`keymapper-v*` 标签及手动运行时执行，并启用 AddressSanitizer、UndefinedBehaviorSanitizer 和泄漏检查。
- 构建直接使用提交的源码，检查构建后无跟踪文件变化。旧的上游构建流程在本 fork 中由完整整合流程替代，避免重新应用历史补丁或按历史标签回写程序版本。

现阶段增强版的应用平台验证范围是 Windows x64；核心另有 Linux 消毒器测试。保留的上游 macOS/Linux 应用打包配方不构成本增强版的平台验收。

## 版本与交付

本次整合保留 `0.3.0-rc.1` 候选身份。程序基础版本来自 `QtScrcpy/appversion`；候选包名及 `build-info.json` 从同一基础版本生成，并记录实际主项目、核心和编辑器提交以及工作流运行编号。

合并和标签构建会产生 Actions 验证记录及运行包，不自动创建或覆盖 GitHub Release。后续正式发布应在新版实体手机、鼠标和具体游戏验收完成后统一候选标识、版本说明和发布标签，再从确定的提交重新构建。

此次整合不加入此前暂缓的音频热补丁，也不改变主窗口关闭到系统托盘的行为。
